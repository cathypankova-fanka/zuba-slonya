# Игра «Украшаем торт» — прототип

Запуск (из этой папки; по file:// не работает):

    python3 -m http.server 8766

Открыть http://127.0.0.1:8766/ . Интерфейс без текста, только картинки.

## Как играть
- Внизу 4 вкладки-картинки: **торт** (6 вкусов), **крем** (6 цветов), **украшения** (12), **свечки** (6).
- **Крем:** провести пальцем по торту — вдоль пути выдавливаются розочки.
- **Украшения и свечки:** тап по торту ставит предмет (свечки — только на верх). Потянуть за предмет — двигает; утащить в красную корзину справа внизу — убирает.
- Кнопки слева: ↶ убрать последнее, корзина — убрать всё. Справа: когда стоят свечи, появляется большая голубая кнопка «подуть» — огоньки гаснут с дымком, играет «С днём рождения» и сыплется конфетти.
- Звук синтезируется в браузере (файлов нет), кнопка динамика в углу.
