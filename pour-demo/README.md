# Прототип «наливаем из чайника»

Запуск (из этой папки):

    python3 -m http.server 8765

Открыть http://127.0.0.1:8765/ — по file:// не заработает (канвас и картинки).
Держишь зелёную кнопку / чайник / пробел — чайник наклоняется и льёт.

Слои (снизу вверх): canvas с жидкостью (маска `img/glass_inner.png` по альфа-каналу) →
SVG-струя (цвета `liquidTop/liquidBottom` из игры) → `glass.png` (стекло поверх жидкости) →
пар → `teapot.png` (вращается вокруг центра дна, носик отслеживается по `meta.json`) → всплеск и брызги.

Картинки режутся из `../sheets/pour_props.png` скриптом `../pour_assets.py`, чашки — из `../sheets/pour_cups.png` скриптом `../pour_cups.py`.
Посуда выбирается по категории: чай — прозрачная стеклянная чашка (`img/cup.png`), кофе — высокая стеклянная кружка (`img/cupmug.png`),
сок и коктейль — стакан (`img/glass.png`). Жидкость везде видна и поднимается внутри стекла; маски внутренности — `img/*_inner.png` (обходят ручки).
Керамическая кружка `img/mug.png` осталась как запасной вариант (в коде `VESSELS.mug`), по умолчанию не используется.
Когда налито, рядом выскакивает карточка с готовым напитком из игры (`img/recipes/<id>.png`, 20 шт.).
Капли (`img/droplets.png`) вырезаны, но пока не используются. Сцена масштабируется под любой экран, телефон проверен.

## Интерфейс для ребёнка (без текста)
- Категории — 4 картинки (`img/cats/`: чай, кофе, сок, коктейль), напитки — картинки готовых напитков (`img/recipes/`) в рамке цвета напитка.
- Налив — большая зелёная круглая кнопка с каплей (или нажать на сам чайник); «ещё раз» — круглая оранжевая стрелка, она пульсирует, когда налито.
- Подсказка — качающаяся рука над чайником, пока ребёнок ни разу не нажал.
- «Готово» — конфетти и карточка с готовым напитком, без надписей. Названия есть только в `aria-label` для взрослых и скринридеров.

## Картинки и звук
- Все картинки — WebP, уменьшены примерно до 2× от размера на экране: вся папка ~0,9 МБ (было ~9 МБ). Исходные PNG режутся скриптами `../pour_assets.py` и `../pour_cups.py`, затем `../pour_optimize.py` превращает их в WebP и удаляет PNG.
- Звук синтезируется в браузере (WebAudio), аудиофайлов нет: шум воды (тон растёт по мере наполнения), бульканье, «поп» при выборе плитки, звоночек при «Готово». Включается после первого нажатия (так требуют браузеры). Кнопка динамика в углу — выключить звук (запоминается).
