# Раскраска — прототип

Запуск (из этой папки; по file:// не работает):

    python3 -m http.server 8767

Открыть http://127.0.0.1:8767/ . Интерфейс без текста.

## Как играть
- Открывается галерея: 36 раскрасок-животных (картинки). Тап — открыть. Квадратик слева сверху — вернуться в галерею.
- Инструменты (значки): **ведёрко** — тап заливает всю область целиком; **кисть** — красит пальцем; **радужная кисть** — сама меняет цвета; **ластик** — тап очищает область. У кисти 3 размера (точки).
- Цвета — 14 больших кружков. ↶ — отменить, корзина — стереть всё, зелёная ✓ — готово (конфетти, мелодия, звёздочка в галерее).

## Как «не выйти за контур»
1. При открытии рисунка строится **карта областей** (каждый замкнутый кусок рисунка — своя область).
2. **Ведёрко** заливает область целиком одним касанием.
3. **Кисть** красит **только в той области, где палец коснулся первый раз**; заведёшь за линию — краска просто не ляжет. Чтобы красить другую область, надо оторвать палец.
4. Заливка чуть заходит под линию, поэтому нет белой каймы; линии лежат отдельным слоем сверху.
